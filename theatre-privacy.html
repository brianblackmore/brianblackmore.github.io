Theatre Calendar

Privacy policy

Last updated: 6 November 2026

This policy explains how Theatre Calendar handles information when preparing and synchronizing theatre bookings with Google Calendar.

Information used

The app uses upcoming theatre bookings recorded in a local workbook. A calendar entry may include the show title, date and time, venue or location, and the name or names of the people attending. If a matching event with a time is found in a source calendar, its time is used. Otherwise the booking is all-day. Its location comes from a matching event when available, or from the workbook's venue and city.

The Google sync uses the booking details needed to create calendar entries, not workbook details such as costs, hotel arrangements, notes, or ratings. Cancelled bookings and reservation placeholders are excluded from person-specific calendar exports.

Google Calendar API use

The sync uses Google's Calendar API to create a dedicated calendar for each configured companion and keep that calendar up to date with their selected upcoming theatre bookings. It adds or updates upcoming events managed by the integration, and removes managed upcoming events when the corresponding booking is no longer planned. Past events are retained.

The app requests the OAuth permission https://www.googleapis.com/auth/calendar.app.created, which applies to calendars created by this app. It does not read or change your pre-existing Google calendars or unrelated calendar data. Source calendar feeds are used by the local sync process to match show times and locations, not copied wholesale into Google Calendar.

Each calendar is shared manually by its owner with the relevant person using read-only event access. Calendars are not made public, and this website does not host calendar feeds.

Storage and sharing

Google receives and stores the event details needed to create the selected calendar entries. The Google authorization token and app configuration are stored in local files on the computer running the sync, not on this website or in the source-code repository. The computer's operator can access those files.

Calendar information is not sold, used for advertising or profiling, or used to train AI models. The app does not share calendar details with anyone automatically; access is controlled by the calendar owner's sharing settings. Anyone who is granted access can view or copy event information.

Your choices

You can change or remove bookings in the source workbook. You can revoke the app's Google access from your Google Account connections. Revoking access stops future API updates, but does not automatically delete calendars or events already created; you can remove those in Google Calendar.

For questions about the workflow or requests concerning calendar information, contact Brian Blackmore through GitHub. Please do not include private calendar details in a public message.

This website

These are static information pages hosted on GitHub Pages. They do not ask you to sign in or submit calendar information, and they contain no analytics, advertising, or tracking cookies. GitHub may process technical request information, such as IP addresses, to operate and secure its hosting service. See the GitHub Privacy Statement.

Changes to this policy

This policy will be updated if the integration's actual behavior or data use changes. The date above identifies the latest revision.
